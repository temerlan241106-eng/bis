# FitnessIT — Gym KBTU

Регистрация с кодом из письма, расписание с фильтрами, запись и отмена, геймифицированный профиль
(уровни, сундуки, рамки, титулы, лиги), подписка Premium с демо-оплатой, панели тренера и админа.
Дизайн «мягкий премиум» (слива, коралл, персик), светлая и тёмная темы. База: локальный SQLite или облачный **Turso**.

👉 **Облачная база, почта и хостинг на PythonAnywhere: пошагово в [DEPLOY.md](DEPLOY.md).**

## Запуск
Самый простой способ:
- **Windows:** двойной клик по `start.bat`
- **macOS/Linux:** `./start.command` или `python3 run.py`

Скрипт сам установит зависимости, создаст `.env`, добавит тестовые данные и откроет сайт в браузере (http://127.0.0.1:5000).
Нужен только установленный Python 3.9+.

## Структура
- `run.py` — запуск одной командой
- `app.py` — создание приложения, конфиг, обработчики ошибок
- `db.py` — схема и подключение: локальный SQLite или Turso (если в `.env` задан `TURSO_DATABASE_URL`)
- `turso.py` — клиент Turso по HTTPS (работает на бесплатном PythonAnywhere)
- `turso_tool.py` — `check` / `push` (залить локальную базу в облако) / `pull` (резервная копия)
- `mailer.py`, `templates/email/` — письма через Gmail SMTP (без настроек печатаются в консоль)
- `plans.py`, `premium.py` — тарифы Free/Premium, страница тарифов, демо-оплата картой или Kaspi QR
- `game.py` — уровни по XP, лиги, титулы и рамки, ежедневный сундук, HUD в шапке
- `static/game.js` — конфетти, всплывающий «+XP», анимация сундука, живая карта на оплате
- `pythonanywhere_wsgi.py` — WSGI-файл для хостинга
- `instance/fitnessit.db` — готовый файл базы SQLite с тестовыми данными (открывается в DB Browser for SQLite); `schema.sql` — схема текстом
- `auth.py` — регистрация, вход, выход
- `schedule.py` — расписание, фильтры, запись, отмена, «Мои записи»
- `booking.py` — правила записи (6 проверок в одной транзакции, включая лимит тарифа Free)
- `userpage.py` — профиль `/profile` и геймификация: уровень, XP, квесты недели, 12 достижений, серия недель, график за 8 недель; рейтинг студентов `/leaderboard`
- `staff.py` — страницы тренера и админа
- `roles.py` — разграничение доступа по ролям
- `demo_data.py` — демо-студенты с историей посещений (для показа профиля, квестов и рейтинга)
- `seed.py` — тестовые данные: 6 залов, 9 типов занятий, 7 тренеров, ~150 занятий на неделю (`python seed.py --extend` добавляет их в уже существующую базу)
- `tests/` — тесты (`pip install -r requirements-dev.txt && pytest`)
- `docs/` — требования, диаграммы, сценарий демо
- `extensions.py` — CSRF и лимитер попыток
- `.env.example` — пример настроек
- `templates/`, `static/` — интерфейс

## Геймификация
- **XP:** 10 за посещённое занятие (15 с Premium), +5 за новую дисциплину, +15 за достижение, +30 за неделю с 3 занятиями,
  +10 за неделю с занятием до 10:00, плюс бонусы: сундуки, +20 за подтверждение почты, +50 за покупку Premium (таблица `bonus_xp`).
- **Уровни (8):** от «Новичка» (0 XP) до «Легенды зала» (850 XP). При новом уровне на сайте салют.
- **Лиги в рейтинге:** Бронза → Серебро (150) → Золото (400) → Алмаз (700); пьедестал топ-3.
- **Ежедневный сундук 🎁:** 5–15 XP, редкий 20–30 (25%), легендарный 50–75 (5%). Free: 1 в день, Premium: 2.
- **Рамки аватара и титулы:** открываются уровнем, сериями, достижениями или Premium; выбираются в профиле.
- **HUD в шапке:** уровень, полоска XP, серия недель 🔥, сундук.
- **Квесты недели** и **12 достижений**: как раньше.

## Подписка
- **Free:** 3 записи в неделю (по неделе занятия). **Premium:** без лимита, x1.5 XP, 2 сундука, золотая рамка, корона в рейтинге.
- Сроки: 1 месяц (2 990 ₸), 3 месяца (7 990 ₸), 12 месяцев (24 990 ₸). Продление добавляется к текущему сроку.
- Оплата **демонстрационная**: проверяется формат карты (алгоритм Луна, срок, CVC), деньги не списываются,
  в базу пишутся только последние 4 цифры. Тест: `4242 4242 4242 4242` (успех), `4000 0000 0000 0002` (отказ).

## Безопасность
SECRET_KEY из окружения · CSRF на всех POST · HttpOnly + SameSite cookie ·
5 попыток входа в минуту · 10 регистраций в час с одного IP · только адреса @kbtu.kz · SQL только с параметрами `?` · пароли хешируются.

## Настройки (.env)
См. `.env.example`: `TURSO_DATABASE_URL`/`TURSO_AUTH_TOKEN` (облачная база), `MAIL_USERNAME`/`MAIL_PASSWORD` (Gmail).
В продакшене: `COOKIE_SECURE=1`, `BEHIND_PROXY=1`, `URL_SCHEME=https`.

## Почта
Регистрация в два шага: форма, затем 6-значный код из письма на @kbtu.kz. **Аккаунт создаётся только после
ввода верного кода.** До этого данные лежат в таблице `signup_codes`: пароль хранится хешем, код HMAC-хешем.
Код живёт 15 минут, на один код даётся 5 попыток, повторно отправить можно раз в минуту.
Старые неподтверждённые аккаунты при входе тоже получают код. Демо-аккаунты и тренеры уже подтверждены.
Настройка Gmail описана в DEPLOY.md, шаг 2.
