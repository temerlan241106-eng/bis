# FitnessIT — Gym KBTU

MVP: регистрация и вход, расписание с фильтрами, запись и отмена, профиль со статистикой, панели тренера и админа.

## Запуск
Самый простой способ:
- **Windows:** двойной клик по `start.bat`
- **macOS/Linux:** `./start.command` или `python3 run.py`

Скрипт сам установит зависимости, создаст `.env`, добавит тестовые данные и откроет сайт в браузере (http://127.0.0.1:5000).
Нужен только установленный Python 3.9+.

## Структура
- `run.py` — запуск одной командой
- `app.py` — создание приложения, конфиг, обработчики ошибок
- `db.py` — SQLite и схема
- `auth.py` — регистрация, вход, выход
- `schedule.py` — расписание, фильтры, запись, отмена, «Мои записи»
- `booking.py` — правила записи (5 проверок в одной транзакции)
- `userpage.py` — страница профиля `/profile`: уровень, серия недель, любимое занятие и тренер, тип атлета, график за 8 недель, достижения
- `staff.py` — страницы тренера и админа
- `roles.py` — разграничение доступа по ролям
- `seed.py` — тестовые данные: 6 залов, 9 типов занятий, 7 тренеров, ~150 занятий на неделю (`python seed.py --extend` добавляет их в уже существующую базу)
- `tests/` — тесты (`pip install -r requirements-dev.txt && pytest`)
- `docs/` — требования, диаграммы, сценарий демо
- `extensions.py` — CSRF и лимитер попыток
- `.env.example` — пример настроек
- `templates/`, `static/` — интерфейс

## Безопасность
SECRET_KEY из окружения · CSRF на всех POST · HttpOnly + SameSite cookie ·
5 попыток входа в минуту · 10 регистраций в час с одного IP · только адреса @kbtu.kz · SQL только с параметрами `?` · пароли хешируются.

## Настройки (.env)
См. `.env.example`. В продакшене: `COOKIE_SECURE=1`, `RATELIMIT_STORAGE_URI=redis://...`,
`BEHIND_PROXY=1` за обратным прокси.
