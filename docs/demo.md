# Сценарий демонстрации: клиент → тренер → админ

Запуск: `python run.py`. Тестовые данные создаются автоматически.

| Роль | Email | Пароль |
|---|---|---|
| Клиент | client@kbtu.kz | Client12345 |
| Тренер | trainer@kbtu.kz (а также trainer2…trainer7@kbtu.kz) | Trainer12345 |
| Админ | admin@kbtu.kz | Admin12345 |

Эти пароли только для демонстрации. На реальном сервере сначала смените их.

## 1. Клиент
1. Войти как клиент. Открыть расписание на неделю.
2. Применить фильтры: тип «Йога», зал «Зал единоборств», тренер, потом «только со свободными местами».
3. Записаться на занятие. Статус сменится на «Отменить запись».
4. Записаться на другое занятие в то же время: ошибка о пересечении.
5. Открыть «Мои записи», отменить запись.
6. Открыть `/admin` по прямой ссылке: ошибка 403.

## 2. Тренер
1. Выйти, войти как тренер.
2. «Мои занятия»: видно, кто записался на занятия.
3. `/admin` по прямой ссылке: ошибка 403.

## 3. Админ
1. Войти как админ, открыть «Админ».
2. Создать занятие на завтра с вместимостью 1 (выбрать тип, тренера и зал). Если тренер или зал уже заняты в это время, будет ошибка.
3. Записать на него клиента, затем второго клиента: «Свободных мест нет».
4. Отменить занятие: оно исчезает из расписания клиентов.
